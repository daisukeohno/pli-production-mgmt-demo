# pli-production-mgmt-demo

サンプル精機株式会社 生産管理システム（品目マスタ・在庫・製造指示）

メインフレーム（IBM Z / CICS / DB2）からGitへエクスポートした、移行前の現行資産一式です。
移行後のコード（Java等）はこのリポジトリには含まれていません。

## システム構成

- IBM CICS上の疑似会話型PL/Iオンライン（BMS画面）
- DB2（5テーブル）
- 画面は3本のみ
  - PM01 品目マスタ保守
  - PM02 在庫照会・入出庫登録
  - PM03 製造指示登録

## ディレクトリ構成

```
db2/
  ddl/    テーブル定義（DDL）
  data/   初期データ（CSV, UTF-8）
src/
  include/  共通コピー句（COMMAREA、メッセージ定義、DCLGEN相当）
  pli/      PL/Iソース
docs/
  design.md 内部作業メモ（保守引継ぎ用。後日削除予定）
frontend/   移行後の新UI（React + TypeScript + Vite + shadcn/ui）。frontend/README.md 参照
```

## 現状について

本リポジトリは棚卸しのため現行保守チームでエクスポートしたものです。BMSマップ本体（.bms）、
各画面のメイン処理（PM01/PM02/PM03本体）は後続の作業で追加予定です。まずは共通部品
（COMMAREA、メッセージ定義、DCLGEN相当、共通ユーティリティ）とDB2定義・初期データのみ
格納しています。

## 既知の注意事項

- チェックデジットの計算方式はコードを正としてください。運用マニュアルの記載が古い場合があります。
- 更新・削除時に「他の端末で更新されています」と表示される場合がありますが、仕様です
（楽観的排他制御）。
